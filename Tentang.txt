MUSIKIFY - PROJECT PEMROGRAMAN TERSTRUKTUR

Fitur:
- Menambahkan lagu ke file lokal
- Melihat, mencari, dan mengurutkan koleksi berdasarkan rating
- Menganalisis jumlah lagu, durasi total, rata-rata rating, rating tertinggi, dan genre terpopuler
- Membuat laporan ke laporan_musik.txt
- Melewati baris file yang rusak dan memberi pesan jika file data tidak ditemukan

Struktur folder:
Musikify_Project/
  main.py
  lagu.txt (dibuat otomatis ketika pertama kali aplikasi dijalankan)
  laporan_musik.txt (dibuat saat pengguna memilih menu laporan)
  musikify/
    __init__.py
    fileio.py
    processing.py
    validasi.py
    testing.py

Menjalankan aplikasi:
  python main.py

Menjalankan unit test:
  python -m unittest musikify.testing

Menjalankan pengujian dari modul testing secara langsung:
  python -m musikify.testing

Durasi diinput dalam detik. Rating berada pada rentang 0 sampai 5.
